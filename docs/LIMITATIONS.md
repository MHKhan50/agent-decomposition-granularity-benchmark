# Limitations and Threats to Validity

1. **Synthetic environment:** all tasks, feature values, and costs are generated by a hand-authored simulator. No real agent traces or user data are included.
2. **Objective dependence:** the oracle and policy ranking depend on chosen objective weights. Different weights can change the preferred granularity.
3. **Simplified task structure:** the simulator abstracts dependencies into a density feature; it does not construct or execute actual DAGs, model heterogeneous worker capabilities, or represent dynamic task arrivals.
4. **Quality proxy:** the quality score is an equation, not human evaluation or task correctness.
5. **No real token or latency accounting:** work units and costs are normalized synthetic quantities, not measured API usage, monetary costs, or wall-clock times.
6. **Limited learner:** the MLP is a small classifier trained on synthetic labels. It is not an LLM and does not demonstrate performance of any commercial agent framework.
7. **Oracle gap:** the oracle sees the realized hidden shocks and is an unattainable reference. Its performance is an optimistic lower bound on objective, not a fair deployable baseline.
8. **Generalization:** independent random seeds reduce direct sample reuse but do not establish distributional robustness. Evaluate shifted feature distributions and alternate simulator equations.
9. **Statistical uncertainty:** the bundled summary reports means only. A publication should add confidence intervals, paired tests, effect sizes, and sensitivity analyses.
10. **Novelty:** related work already studies graph-based planning and parallel multi-agent execution. The benchmark's narrow decomposition-granularity framing is a research direction, not a novelty guarantee.
